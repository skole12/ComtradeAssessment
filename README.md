# Customer Discount Management API

A simple application for managing customer discounts.

## Features

- Assign Discounts – Manage discounts for customers.
- Import Campaign Results – Import campaign results from CSV files.
- View Merged Data – Access and review merged discount and campaign data through a SOAP API.
- Automated Jobs – Daily jobs for activating and deactivating campaigns automatically.
- JWT Authentication & Authorization – Secure access using JWT tokens with role-based permissions.
- User Management – Manage users with seeded roles, including a Super Admin account.

## Technologies

- .NET 9
- SoapCore
- SQL Server
- Hangfire
